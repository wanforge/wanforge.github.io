# Contributing to Anti-Slop Design

We welcome contributions from designers, frontend engineers, and AI developers working to eliminate AI slop and advance human-grade software interfaces.

---

## Ways to Contribute

1. **Propose New Anti-Patterns:** Have you spotted a new generic AI UI trope generated by modern LLMs? Document it with:
   - What the bad pattern looks like in code.
   - Why it degrades UX or commercial efficacy.
   - The concrete production replacement.
2. **Add Evaluation Benchmarks (`evals/evals.json`):** Add real-world task prompts and expected outcomes following the `anthropics/skill-creator` schema.
3. **Refine Design Archetypes:** Propose new battle-tested CSS token sets for specialized domains (e.g., Spatial Audio, Clinical Health, CAD tooling).
4. **Improve Accessibility & Performance Rules:** Suggest stricter WCAG 2.1 AA heuristics or animation timings.

---

## Submission Guidelines

- All modifications to `SKILL.md` must maintain **single-file self-containment** and remain in **concise English**.
- Run the frontmatter validation check before opening a PR:
  ```bash
  python -c "import re; c=open('SKILL.md').read(); assert re.search('^name:', c, re.M) and re.search('^description:', c, re.M)"
  ```
- Use conventional commits: `feat:`, `fix:`, `docs:`, `chore:`.

Thank you for helping keep AI-assisted software beautiful, tactile, and human-crafted!
