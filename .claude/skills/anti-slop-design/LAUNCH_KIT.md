>

> 2. Emojis (`🚀`, `🔥`) plastered on buttons and sidebars instead of real SVG icons.
> 3. Metrics repeated 3 times across cards because the model generated them in isolation.

> 
> To fix this, I downloaded and analyzed over 100 design skills from GitHub and `skills.sh`, plus Anthropic's official `skill-creator`.
> 
> Most existing skills either:
> - Hallucinate mouse clicks ("click the magic wand in the inspector" — impossible in a CLI), or
> - Explicitly avoid product UI ("Not dashboards, not data tables" like tasteskill).
> 
> So I synthesized everything into **Anti-Slop Design**: an autonomous Principal Design Technologist skill that you can install in 5 seconds.
> 
> **Key features:**
> - **The 12 Banned AI Slop Matrix:** Explicitly forbids the worst AI design tropes.
> - **The 1-to-3 UX Law:** 1 focal point per zone, max 3 secondary actions.
> - **8-State Interactive Feedback:** Every button/input has default, hover, focus-visible, active (scale 0.97), disabled, loading, error, and success states.
> - **Emil Kowalski Animation Timing:** Instant (0ms) for high-frequency workflows, snappy ease-out for modals.
> - **7-Axis Pre-Emit Quality Gate:** The agent grades its own work before concluding.
