The 12 Banned AI Slop Anti-Patterns

ENFORCED IN AGENT LOOP
Anti-Pattern Vibe-Coded AI Manifestation Mandatory Production Replacement
The "AI Dark Mode" Blob radial-gradient from indigo-600/purple-900 blurred in corners Deep monochrome obsidian surfaces (#09090b) with 1px hairline border
Monotonous Slate/Indigo Generic bg-slate-900 text-slate-400 bg-indigo-600 boilerplates Curated semantic tokens (OKLCH/HSL) with distinct brand personality
Cookie-Cutter 3-Card Grid Three identical rectangular cards with glowing hover borders Dynamic asymmetric bento, split-panels, or sequential workflow rows
Raw Emojis as UI Icons Plastering raw emojis (🚀, 🔥, 💡) inside buttons and cards Crisp single-weight vector SVG icons (Phosphor, Lucide, Heroicons)
Fabricated Vanity Stats Filler cards: "+99.9% Uptime", "10x Faster", "50k+ Users" Real domain telemetry or remove the card entirely. Zero vanity metrics
Screaming Eyebrow Labels Tracked-out uppercase labels above every heading: OVERVIEW, FEATURES Sentence-case hierarchy, subtle metadata tags, or omit if self-explanatory
Single-Word Italic/Color Accents Headlines with one word italicized in glowing gradient text Uniform, confident typographic weight. Let the whole statement carry authority
Redundant Metric Duplication Repeating total clicks/revenue in header, sidebar, and inside multiple cards Single source of metric truth. One primary KPI summary per viewport
Card-Level Filter Pollution Duplicating date pickers or dropdowns inside individual cards Unified page-level control bar that synchronizes all views
Vanity Space-Wasters Giant 3D globe or map taking 60% viewport with zero deltas Compact horizontal bar comparisons, sparklines, or tabular comparison rows
Missing Interactive States Buttons with only hover effects; lacking :focus-visible, active, loading 8-State interactive feedback system with tactile active scale(0.97)
Broken Placeholders & Links via.placeholder.com, broken Unsplash URLs, or blurry stock images High-fidelity inline SVGs, semantic CSS abstract shapes, or verified local assets
