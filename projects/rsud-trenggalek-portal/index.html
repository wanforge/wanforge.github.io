RSUD Trenggalek Portal

Internal Hospital Portal · Single Source of Truth

Central web portal for RSUD dr. Soedomo Trenggalek that brings hospital information, services, and internal contact pathways into one searchable place. Built to give staff a fast, reliable reference and reduce daily friction in finding the right department or document.

Backend

Laravel 12

modern PHP runtime

Frontend

React + Tailwind

fast, accessible UI

Cache & Queue

Redis

snappy reads, async jobs

Key Achievements

  • Centralized hospital info, services, and internal contacts into one consistent portal.
  • Modern Laravel 12 stack with React frontend for fast page transitions and accessible UI.
  • Redis-backed caching layer for snappy reads on frequently accessed data.
  • Queue management ready for asynchronous background tasks (notifications, sync, reports).
  • Scoped to internal staff use — built with privacy and access control in mind.
